# 歌单歌曲倒序（beta.26）

自建歌单内点击“排序”，新增“倒序”开关；反转当前默认/歌曲名/歌手名/时长排列，再次关闭可恢复正序。列表、歌曲点播和播放全部使用同一排列；随机模式保留随机行为。排序键及方向在当前页面的系统状态恢复中保留，不同歌单独立。

本功能只派生展示和播放顺序，不调用云端重排、不改变本地关联或云端歌单原始曲目顺序。进入原有“编辑”前恢复默认正序，避免用户在真实云端编辑列表上重复反转。

## 新增和删除曲目

每次歌单数据更新都从最新原始列表重新排序，不把上次倒序结果当作源数据。服务器前置的新曲目，在默认倒序视图中出现在末尾；其他排序键继续按各自规则排列。删除、分页补全或重新加载后同样重新派生，保留倒序开关。

加载中的旧分页响应按最新曲目 ID 合并，保留已加入的新歌，不补回刚删除的歌，也不重复加入已存在的曲目；待加载 ID 从合并后的列表重新计算。播放使用补全结束时的最新快照。

正在播放的队列不因列表更新而中断或重排。下一次点播歌曲或播放全部时先补全当前曲目，再使用新排列；已改变方向或成员的旧队列不能仅因歌单名称相同就被暂停/继续。匹配正确的现有队列仍支持立即暂停/继续，以来源 ID 和种类区分同名歌单/专辑。

## 分页和失败

倒序需要全量曲目，不能把已加载的前 1000 首当作完整歌单反转。开启或保持倒序时，刷新后的分页数据也先补全；未完整时隐藏不正确的部分结果，显示加载状态或手动重试入口。自动请求按服务器曲目 ID 列表去重，不因每次追加一页而重新取消或无限重试。加载失败时不改动原队列、不用部分列表冒充完整倒序。

共享 ViewModel 为现有点播/全部播放方法增加可选排序重载，保留旧签名和桌面调用；完整加载复用原有等待分页、取消和错误提示逻辑。Android 排序 UI 仍使用原组件，增加独立方向状态。播放器和媒体源实现不改动。

## 验证边界

单元用例覆盖每个排序键、反转恢复、空/单曲、1205 首以及新增和删除；共享用例覆盖方向改变、队列成员改变、随机与已加载前缀的恢复判断。原生 UI 覆盖真实排序弹层、详情列表、点播回调、新曲目更新、编辑恢复及分页重试，使用受控曲目和回调，不创建真实云端歌单。网络分页补全及真实音频顺序仍需真机试听验证。
