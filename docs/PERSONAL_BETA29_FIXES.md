# beta.29：逐张接续播放与专辑封面显示

全部播放只打开当前排序的第一张专辑，随后自动播放下一张。随机播放只把所选专辑洗牌一次，专辑内曲序不变，一轮内每张专辑出现一次。

- 播放开始不等待全部专辑读取完毕。当前专辑播放期间仅预读下一张，进入下一张后再读取后续专辑。
- 接续任务独立于页面生命周期，离开专辑页仍然有效。主动更换播放队列、改为单曲循环／歌曲随机或切换账号会停止旧任务，避免旧结果插入新队列。
- 每首歌仍经过现有播放路径：已配对本地文件优先，下载与缓存按现有策略处理，在线地址不可用时允许 JS 换源。准备专辑只读取曲目信息，不要求网易云提供音频地址。
- 优先使用已打开专辑的账号元数据缓存，也支持本地专辑配对时已保存的在线曲目表；不按文件夹名称猜测曲目。
- 需要联网读取时，详情请求串行并限速。短暂网络、风控和服务端错误最多尝试三次；后续某张仍失败时提示其名称并跳过，当前专辑继续播放。
- 设置 → 页面与布局 → 收藏专辑页增加“仅显示专辑封面”。打开后隐藏卡片文字及歌手分组标题，封面保持可点击与读屏描述；默认关闭，设置可持久保存。
- 歌手页移除“默认顺序”入口，菜单与弹窗统一称为“只显示录音室专辑”；配对歌手按钮简写为“手动修正”，排列在“重试资料库”之前。
- 发布时间排序兼容 1970 年以前的负时间戳；零值仍表示未知时间。

接续列表保存在当前应用进程中；关闭或重启应用后，已加载曲目沿用原队列恢复，未预读专辑需要再次点击全部播放。

沿用 beta.28 的严格元数据匹配（允许重制／豪华版标识，区分 Live）、菜单入口及统一设置样式。个人包名与原签名保持一致，版本号为 2.0.0-beta.29，versionCode=2000029。

验证包括二十张专辑只保持一张预读、取消初始准备、离页继续接续、切换队列隔离、瞬时错误重试、缓存复用，以及封面开关的实际 Compose 渲染和 DataStore 重建。在线验收读取二十张真实专辑并通过队列位置变化验证接续顺序；此项不等于完整听完所有音频。最终结果记录在交付目录验证清单中。
