# beta.28 修复与仓库收敛

本版从本地 beta.27 完整个人版与 poesein/Melodia main 合并。远程原基线较旧，缺少 beta.27 的个人音乐库、收藏专辑、人工修正及严格匹配等文件；此次保留这些功能并合入官方更新和先前有效修复，不向官方提交 PR。

- 歌手三个竖点仅保留资料库设置入口及屏蔽功能；手动修正移入资料库设置，复用原记录。恢复全部继续使用资料库设置中的现有入口。
- 收藏专辑的顺序播放／专辑随机不再因一张专辑不可读取而整批失败。跳过项明确提示；全部失败时不替换旧队列。仍只打乱专辑块，保留专辑内曲序、取消及账号隔离。
- 收藏专辑页新增发布时间从新到旧／从旧到新；优先使用列表自带发行时间，缺失时按需读取并缓存专辑详情。未知时间排在末尾；排序选择继续使用原 DataStore。歌手专辑页也保留发行时间排序。
- 喜欢的音乐歌单显示三个竖点，新增编辑喜欢的歌曲入口，进入已有多选编辑。
- 个人音乐库及本地音乐主页栏目共用其他设置的行距、15/12sp 文字、主题色和 MelodiaSwitch；歌单显示方式与列数改为设置行和选择弹窗。
- 严格换源改为歌曲、完整歌手集合、专辑匹配，已有时长和版本信息再进一步检查。允许同专辑重制、豪华、周年等发行差异，拒绝 Live 等不同录音。详见 STRICT_AUDIO_FALLBACK.md。

GitHub 中 ahead／Contribute／Sync fork 是个人分支差异提示，不代表失败。保留个人改动后 ahead 仍会存在；不要用强制同步丢弃个人提交。历史合并提交与失败运行保留，最新 main 的测试和 CI 结果才表示本轮状态。
