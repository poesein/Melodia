# beta.25 修复

## 手动补回专辑的时间顺序

`ArtistAlbumCorrections.apply` 以前把手动添加项放在自动列表之后，现按发行日期与自动项共同倒序排列。自动项优先沿用资料库的原始发行日，避免最近重制的老专辑重新被排到最前；手动添加项使用网易云发行时间，分页或离线期间保留已保存快照。没有可用日期时放在末尾。同日保持稳定顺序。

修正编辑列表也按发行时间排序。仅隐藏或暂停修正时保留自动列表原顺序，保存的选择、版本关联与曲数例外保持不变。

## 新建歌单默认显示

保留 beta.24 的现有显示集合，通过官方创建事件只加入刚创建的 ID，覆盖普通新建、加入新歌单及文本导入。应用启动时注册监听，不要求先进入个人音乐库；没有操作创建时不写布局文件。已有隐藏项、缺失项、列数、栏目和排序均不重置。

这是应用内创建行为；在其他客户端新增或收藏的歌单仍可进入“选择显示的歌单”勾选。既有隐藏项无法区分“主动隐藏”和 beta.24 未自动选中，升级不会擅自全部显示。

不改播放、音源、本地关联或资料库缓存格式；继续使用同一个人包名和签名，后续上游合并检查点限于 Android 依赖注册、专辑展示合并与个人页显示设置。
