# 个人音乐库（beta.24）

新增独立的 Android 根页，原音乐库保留。底部页面设置可排序和关闭“个人音乐库”；底栏上限由五项改为六项。升级时为新入口补一项，明确关闭后不再自动打开；旧的音乐入口迁移仍保留原五项自定义布局。

## 交互

- 左侧恢复原音乐库的头像入口和“音乐库”标题；头像按原逻辑打开侧栏或登录。
- 右侧依次为全局搜索、音乐符号的听歌识曲、新建及 TXT/粘贴文本导入、本地音乐文件夹。搜索退出回到个人音乐库原帧。
- 原齿轮入口迁入总设置 → 个人音乐库，沿用 beta.23 的同一份布局、列数、数量和排序记录，不做重置。
- 歌单复用原音乐库的数据与排序，最多预览五行，实际不足五行时不占空行；封面同样按实际行数收缩。点击栏目“全部”可访问全部收藏，预览上限不删除记录。
- 歌手、专辑采用本地音乐主页的横向栏样式。点击打开原详情页。
- 总设置中可添加本地最近添加、本地歌单、本地歌手、本地专辑。七个栏目同级排序与显隐，新增本地栏目默认关闭；开启后复用原本地曲库、播放及歌曲菜单，不复制数据。不需要网易云登录；仅在开启本地栏目或打开样式管理时读取本地曲库，需要权限时由用户点击授权。
- 本地音乐设置增加四个原有栏目的排序和隐藏；原统计卡、快捷入口、扫描与本地歌单数据不变。
- 歌手、专辑及本地歌单的横栏默认显示 10 项，可设 1–5000，或 0 显示全部。网易云歌单保持五行预览策略，通过列数调整布局。
- 歌单、歌手、专辑支持条目上移、下移及置顶，直接保存；管理面板可查找条目。查找后的移动仍按完整顺序处理。本地条目顺序和数量在个人音乐库、本地音乐及本地“全部”列表共用（完整列表不受横栏数量限制）；网易云条目顺序独立保存，原音乐库仍使用其原设置。新增条目排在已排序条目之后，暂时缺失的条目 ID 不删除，扫描重新发现后仍可参与排序。
- “选择显示的歌单”对每个网易云歌单（包括虚拟听歌排行）直接勾选保存，预览和“全部”共用筛选。首次未设置时显示全部；开始选择后只显示选中的 ID，新增歌单可在此勾选。选择不会删除服务器收藏；暂时不在当前加载列表中的已选 ID 保留。原音乐库仍可查看全部收藏。
- 虚拟听歌排行没有网络封面地址，新页使用与原音乐库一致的蓝绿渐变和排行符号，列表、封面及设置选择页均可离线显示。

## 滚动边界

把文本导入中已验证的滚动边界提取为 `core/ui/scroll/ExpandedSheetScrollBoundary`。个人音乐库的歌手/专辑/歌单“全部”、条目排序与歌单选择均连接实际列表状态；专辑修正、资料库歌手候选、本地关联、加入本地歌单、歌曲操作、底栏自定义、歌手选择、共用歌单收藏/导入目标和播放队列也使用同一边界。

仅在弹层已完全展开时消耗向上的剩余位移与惯性，避免列表到底后的重复 settle；保留列表自身滚动、横向滑动和向下关闭。匹配报告等使用普通 Dialog 的固定页面没有底部弹层父级，无需加入该边界。静态无滚动菜单不改动。

## 边界与存储

Android 新代码集中于 `feature/personallibrary`；共享层仅扩展底栏条目和迁移。原 `LibraryScreen`、播放、匹配和专辑资料库逻辑无需修改。

两页栏目布局保存在 `music_page_layouts.preferences_pb`，本地条目的数量和顺序共用 local 记录。新增可空 `visiblePlaylistIds` 为加法字段，旧记录缺失时继续显示全部；不写入账号、扫描过滤、音乐数据或关联记录。设置事务内读取最新值，防止两处保存互相覆盖；旧/未知栏目会规范化，未知版本或损坏的 JSON 拒绝覆盖并提示。个人页与总设置共用 `personal-library-data` ViewModel key，原音乐库保留自己的筛选现场。

合并后续官方更新时重点检查底栏枚举/布局迁移、根页快照、新页面路由以及本地主页栏目区域。新枚举成员需要官方新增的穷尽分支同步接入。此设计缩小冲突范围，不保证未来官方重构无需适配。

## 验证要点

除既有回归外，检查：列表和网格不足五行后，歌手/专辑实际位置上移；五列模式仍最多五行；更多展示全部；设置排序、隐藏与模式切换；两页独立持久化；旧导航快照、独立回退栈和搜索往返；个人入口迁移后可隐藏。覆盖升级需保持原包名和签名，并比较既有匹配/资料库偏好内容。
