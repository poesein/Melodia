# 可选严格换源

设置 → 音源设置 → 严格换源模式，默认关闭。该模式在原自动换源开关之上增加拒绝条件；官方播放、本地文件、已确认的本地关联与官方下载仍可使用。没有官方参考时拒绝社区完整音频，必要时保留明确标注的官方试听。

## 责任边界

- `StrictSourceCandidatePolicy` 只筛选候选元数据。主标题、歌手集合、已知时长及版本标记须一致；多个不同 ID 通过时拒绝自动选择。中性的精选集/再版专辑名不同本身不证明是另一录音。关闭严格模式仍使用既有 `SongMatcher`，本地关联的匹配策略独立。
- `SourceResult` 保留实际平台、平台歌曲 ID、插件及候选；它们不是实际音频已核验的证据。
- `PlaybackSourceKind` 默认 `UNKNOWN`。官方仓储显式设置 `OFFICIAL`，并把 `freeTrialInfo.start` 从秒转换为毫秒。不能根据 URL 域名、插件自报、ID3 标签或请求成功码伪造官方来源。
- `AudioSourceRouter` 在严格模式只接受官方来源，或由宿主 `StrictAudioVerifier` 产生的片段证据。官方试听缺失、起点未知、无宿主实现、歧义或比对失败都不放行社区 URL。旧远程 UNM 响应不具备此契约，严格模式不调用它；聚合搜索的裸 URL 也不能通过 `localUri` 绕过。
- Android 的 `AndroidStrictAudioVerifier` 从官方试听与实际候选解码 PCM：检查候选容器的完整时长，再比对同一时间偏移上的两段有声音频，累计至少 6 秒、最小归一化相关度 0.94，允许有限编码偏移和全局反相。允许转码、声道和音量变化，并拒绝静音、短片段冒充完整歌曲等。

**片段一致只能证明取样部分与官方参考一致，不能保证未取样的整曲，也不能防止远端在核验后改变资源。** 同一录音的不同母带、速度差异、未知试听起点、无法可靠解码/定位/取得时长的格式可能被安全拒绝；拒绝不是“已经证明错曲”。默认关闭使用户可以选择原有可用性。

## 网络、缓存与取消

`BoundedAudioRangeReader` 用 64 KiB Range 支持容器头、片段定位及尾部元数据随机读取。每输入应用读取音频预算为 2 MiB；网络单次调用最多 5 秒，整个核验检查约 30 秒截止时间。取消在网络读取和解码循环中传播。最多三次重定向，拒绝 HTTPS 降级和 URL 用户信息；不发送源脚本的认证头或 Cookie，不记录签名 URL。若有 ETag，后续读取使用 `If-Match` 并拒绝对象变化。未消费的异常响应先取消再关闭，避免为连接复用继续消耗响应体。

严格模式不读取/写入历史 Media3 流缓存，离线缓存索引也不把这些无来源的条目标为可播；原文件保留供关闭严格模式后使用，不做破坏性迁移。已有下载和本地匹配记录不删除。自动“边听边存”的新增任务及自动交叉淡化在严格模式暂不触发；用户主动下载、已有官方下载和本地播放仍保留。

播放器为异步解析和预取绑定策略 epoch，使用前再读实际设置；切换时先使旧结果失效，再取消活动解析、预取、淡化与恢复任务。暂停的旧网络媒体项也清空后重新解析，不能通过恢复按钮继续播放。恢复证明同时绑定队列 ID、已加载 ID、证明 ID 和实际 URL。媒体通知及外部控制器的播放意图经过同一入口；严格模式禁止外部控制器直接注入媒体项。真正的 `content:` / `file:` 本地源保留，HTTP `localUri` 不算本地。

## 与上游合并

新增字段都有兼容默认值，不更改 Room 表或本地关联格式；旧配置缺少开关时保持关闭。音频比对、候选筛选和播放器策略分别放在独立文件，平台实现通过可选接口注入；没有实现的平台严格拒绝，不把空实现当成通过。合并上游时保留官方仓储的来源标记与试听起点转换，并检查所有新增播放入口是否携带来源、是否经过策略门槛。

beta.27 已移除个人独立音乐页及其搜索/识曲入口；主页仍保留官方音乐与最新内容。新增收藏专辑页复用正常播放队列入口，本地优先、严格源证明和旧缓存隔离继续由同一套播放策略执行。专辑随机仅打乱专辑块，并在播放器初始化后关闭全曲随机/单曲循环，保持专辑内部曲序。

## 验证范围

仓库测试覆盖严格开关默认值、关闭兼容、候选歧义/版本/缺字段、来源与证据门槛、取消/模式变化、PCM 正负例、HTTP Range/预算/对象变化、播放器恢复与外部命令策略、导航往返。Android 11 模拟器另用生产解码器和本机 HTTP 服务器验证实际 MP3/AAC 转码、音量和偏移，验证旧完整缓存普通模式可用、严格模式不可用；真实网易云 U2《One》官方试听也与本机提供的同专辑音频通过比对。后者没有调用社区 JS 后端，不能写成对所有源的全链路保证。
