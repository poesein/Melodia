# 严格换源（beta.28 起）

严格模式按用户确认的规则核对歌曲信息，不依赖官方试听，也不下载音频片段做波形比对。默认关闭，原开关和已有设置保持不变。

## 匹配要求

- 歌曲名、完整歌手集合、专辑名必须匹配。统一大小写、Unicode 宽度、标点和空格，不接受歌名子串或部分歌手命中。
- 同一专辑的重制、豪华、周年纪念、扩展等明确发行后缀可忽略；普通括号中的作品副标题、Part II 等保留。不同专辑不能因为歌曲同名而通过。
- Live／现场、伴奏、混音、翻唱、不插电、重新录制及明确语言版本仍区分。重制版可匹配，现场版不能替代录音室版。
- 双方均有时长时再核对：容差为 1%，最多 3 秒。缺时长不再单独阻止完整的三项身份匹配。
- 多个相同歌曲、歌手、专辑的发行 ID 可以选择最接近已知时长者，不再全部当作歧义拒绝。
- 实际请求的平台与候选平台、歌曲 ID 必须一致。跨平台先搜索对应 ID，不把网易云 ID 当作其他平台 ID 使用。

## 播放与数据

官方完整链接优先；官方无完整音频或试听时仍会运行社区源。严格匹配成功后生成绑定目标歌曲、实际平台、平台歌曲 ID 和链接的摘要，播放器继续使用现有策略代次、取消和恢复检查。`STRICT_VERIFIED` 是兼容沿用的内部标识，beta.28 表示严格元数据匹配，不表示实际录音的声学鉴定。

只提供裸 URL 的旧远程 UNM 响应没有完整候选信息，在严格模式仍不使用。本地优先、手动关联、下载及旧文件保留；继续绕过旧的无来源流缓存。没有任何匹配候选时暂停并显示歌曲信息不一致提示。

历史 PCM 比对工具与其单独算法测试保留供研究，已从播放路由与依赖注入中移除，不再是严格换源门槛。beta.27 及更早的官方参考音频要求已被本规则取代。

## 验证

单元回归包含无官方参考、无试听起点、歌曲／歌手／专辑反例、已知时长差异、重制版正例、Live 反例、同录音多 ID、来源 ID 对应及中途切换策略。真实源测试使用独立的临时偏好，不修改用户音源配置，也不将脚本密钥写入仓库。
