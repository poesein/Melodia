# beta.31：歌单操作集中到三点菜单

移除曲目列表上方的整行快捷胶囊，将编辑歌曲、添加音乐、调整顺序、歌曲排序、编辑歌单信息集中到现有三点菜单。编辑歌单信息只保留一项，区分向当前歌单添加音乐与将歌曲添加到其他歌单。

沿用原有底部菜单的主题、图标、字号、间距和滚动方式。喜欢歌单保留编辑歌曲与本地排序；只有自己的普通歌单提供添加音乐、手动调整顺序和编辑信息。空歌单仍可添加歌曲与编辑信息；需要曲目的动作禁用。

排序规则仍按原作用域保存，手动调序仍先恢复真实歌单顺序并加载完整曲目，再进入拖动模式。删除快捷行后同步修正当前播放曲目的定位下标。多选、取消喜欢与播放行为沿用 beta.30。

验证覆盖：列表不再显示快捷行、三点菜单的各操作只出现一次、喜欢歌单与普通歌单权限区别、排序与倒序、手动调序前恢复真实顺序，以及现有多选操作。安装包继续使用原个人包名和签名覆盖升级，保留原本地关联数据。
