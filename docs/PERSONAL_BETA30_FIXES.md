# beta.30：统一歌单选曲编辑与连续取消喜欢修复

喜欢的音乐、自己创建及收藏的普通歌单通过同名“编辑歌曲”进入多选。自己的普通歌单将实际曲序编辑单独标为“调整顺序”，名称／简介／封面仍在“歌单信息”中。喜欢歌单沿用系统权限，不提供改名、删除或手动调序。

多选支持加入喜欢、取消喜欢、添加到指定歌单、下一首播放与下载。自己的普通歌单额外提供“移出歌单”；移出普通歌单不会取消红心，取消红心不会从其他普通歌单删除歌曲。添加目标排除当前歌单和系统喜欢歌单，喜欢标记统一走红心接口。

界面沿用原有胶囊按钮、悬浮工具栏、Material 图标、深色主题和确认弹窗。进行长批量操作时显示进度并禁用重复提交；关闭多选可请求停止，在当前歌曲完成后停止，未处理及失败项目保留勾选，可直接重试。

## 排查证据与修复

1. 原红心仓储每次操作先保存整个旧集合；并发中的某个请求失败，会把整个旧集合恢复，撤销其他已成功操作的视觉状态。改为服务端确认后只更新当前歌曲，不再整组回滚。
2. 并发或较早发出的喜欢列表读取可能晚到，覆盖刚取消的红心。短期保存已确认的逐首写入结果，合并读取结果，防止旧刷新重新插入已移除项目；账户切换隔离旧请求。
3. 页面用名称识别系统喜欢歌单，但旧的取消成功处理仅比较歌单 ID 与用户 ID，两者通常不同。统一识别条件，成功后精确更新曲目、ID 表和数量，不再逐次重新抓取整张歌单；旧详情响应也不能恢复已确认移除的行。
4. 旧批量只支持加入喜欢，并在部分成功时退出多选。增加取消喜欢及成功／未完成 ID 结果，失败项保留，重试只处理剩余项目。
5. 红心写入通过同一串行通道，间隔至少 800 毫秒。瞬时网络、429 和服务端错误有限重试；持续受限时暂停连续请求并明确提示。没有昨日现场响应日志，不能声称网易云存在固定的“二三十首”阈值。
6. 收藏弹窗不再将过期的整组红心集合回写；更新失败时不再继续提示整批成功。批量加入／移出同步歌单包含状态缓存。

使用模拟接口覆盖五十次连续取消、第三十一次瞬时受限、持续受限、旧刷新晚到、歌单 ID 与用户 ID 不同、部分失败、停止及权限隔离；不拿用户真实喜欢列表做删除试验。实际测试数量、签名及覆盖升级结果见交付验证清单。
